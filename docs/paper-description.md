# USPEXKit — A Post-Processing Toolkit for USPEX Molecular Crystal Structure Prediction

**USPEXKit** is an open-source Python post-processing toolkit designed to accelerate molecular crystal structure prediction within the USPEX evolutionary algorithm framework. It provides a unified pipeline of twelve command-line utilities covering trajectory conversion, feature extraction, high-throughput DFT screening, and broken-molecule repair. The core innovation is a machine-learning surrogate model that combines Gaussian Process regression with a Random Forest fallback to predict crystal density and lattice energy from a 10-dimensional energy–density descriptor vector, which encodes GULP force-field energy decompositions — bond, angle, torsion, van der Waals, Coulomb, and three C–H–X hydrogen-bond channels — together with the packing density. The GP kernel is a composite of a DotProduct kernel capturing linear trends, a Matérn kernel (ν = 2.5) with automatic relevance determination for local nonlinear coupling, and a WhiteKernel for observation noise. A nearest-neighbor residual metric in the 10-D feature space serves as an extrapolation risk indicator: when the residual exceeds a threshold of 10, the prediction falls back to the Random Forest estimate or, in extreme cases, to a scaled mean-density prior. The GP regression is implemented via a GPyTorch backend with a scikit-learn-compatible API, supporting L-BFGS hyperparameter optimization with multiple restarts and pickle serialization. The toolkit further integrates SIESTA DFT calculations with an automatic structure-matching deduplication mechanism that reuses previously computed results, substantially reducing redundant DFT workload. Designed for energetic molecular crystals containing hundreds of atoms per unit cell, USPEXKit has been successfully applied to the co-crystal prediction of TNT and CL-20, demonstrating its utility in guiding evolutionary searches toward high-density candidate structures while maintaining computational tractability.
